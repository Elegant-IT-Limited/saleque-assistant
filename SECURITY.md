# Security

This is a reference build, not a deployed service, but it handles the same kinds of data the production system does, so we treat reports seriously.

If you find a vulnerability, please do not open a public issue. Use GitHub's private vulnerability reporting on this repository (Security tab, "Report a vulnerability"). We will acknowledge within 5 working days and keep you informed until it is resolved.

Please include the steps to reproduce, the version or commit you tested, and what you believe the impact is.
